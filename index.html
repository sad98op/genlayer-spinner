Design concept

  • 5 nodes — the first validator set in Optimistic Democracy
  • Static Strong Mark — follows brand guideline (never rotate the mark)
  • Traveling pulse — soft consensus arc rotating around the ring
  • Kinetic Cobalt + gradient — official brand colors only
  • Pure CSS — no JavaScript, works offline, respects reduced-motion
